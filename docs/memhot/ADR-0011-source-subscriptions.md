# ADR-0011 信息源订阅与可分页的研究候选库

日期：2026-10-13；状态：采用。

## 目标与边界

用户在“个人偏好 → 我的订阅”管理常读来源。采集服务定时获取材料，研究 agent 根据兴趣和可编辑的个人认知挑选原文、核对事实并组织日报。采集不调用模型、不占研究额度，不把搜索摘要当作已读证据。

公开目录来源、个人订阅关系、候选发现、已读证据分别建模。协议 DTO 在 HTTP 边界验证和转换，前端不获得原始私人订阅地址或服务密钥。现有库已能完成 HTTP、XML、SQLite、UI 和 Pi 编排，没有引入新依赖。

## 订阅与采集

`subscription_sources` 保存来源和带期限的采集租约；`subscriptions` 保存租户自己的分类、名称和启停；`subscription_items` 保存来源内容。只有用户明确选取的服务器目录 ID 可以共享采集缓存；自定义地址即使相同，也保持用户隔离。私人源只进入私人研究或私人日报。取消最后一个订阅后清理孤立来源，清空账户同时移除关系和对应私有内容。

采集独立于模型队列：全局最多 4 个租约、同一主机最多 1 个；HTTP 30 秒超时、90 秒租约、15 分钟刷新。失败退避从 2 分钟到 6 小时，主动更新有 60 秒冷却。完成写入需同时匹配租约和有效订阅，避免取消订阅后旧任务重新写入。URL/DNS/跳转均通过服务端网络边界校验。日志和来源状态不返回带凭据的地址。

文章按原始发表日期排序，无效日期为空，不把抓取时间伪造为发表时间。聚合源单独保留发现日期。来源内容保留 30 天、每源最多 1000 项；这是缓存保存策略，区别于研究候选的条数截断。初次读取 RSS 最多解析 200 项，遵循上游实际提供的列表。深度研究可搜索整个已收录集合并继续分页，不能把首页当作全部历史。

旧 `profile.feeds` 启动时一次性迁移为用户私有关系并清空旧字段。仅为稳定外部 API 保留 legacy feed 契约，内部不双写；老客户端不会删除新界面管理的订阅。迁移验证在数据库副本上检查除 feeds 外的所有个人设置、原记录、来源归属和既有订阅不变。

## 搜索与候选资料

主搜索先使用已有的 SearXNG 原始响应解码器，保留其完整有效列表，避免 Pi 插件每次最多 20 条的接口再次裁剪；Pi 保留网页读取及免费搜索回退。免费 SearXNG 与用户选配的 Tavily/Exa 搜索可并行返回。先交错排列，再规范化网址去重；不因免费结果充足丢弃付费结果，也不截断为前 8/12/32/40 条。解码保留响应中所有安全有效的结果。上游单次响应规模仍受其 API 合约约束，agent 可细化问题重复搜索。

`agent_candidates` 按租户、研究运行及来源标识保存候选；每次搜索有独立 collection，避免新结果被旧结果的首页遮住。同一来源在不同 collection 共享稳定标识。`list_candidates` 每页 20 项，通过不透明 cursor 继续读；关键词先过滤完整集合再分页。页大小只控制一次上下文体积，不是候选总量上限。游标绑定用户、任务、查询、集合和快照边界，不能跨账户复用。候选与游标 24 小时清理，删除个人上下文后不可访问。

模型可以比较标题和摘要与用户偏好，再通过 `read_source` 选取原文；未读线索标记 `candidateOnly`，不得作为事实引文。只有实际读取的材料进入工作证据集合，不再有 40 份文献的固定上限。初始检索和原文预读取有时延预算，未预读的候选仍可继续选择。日报最后的时效、逐字引文和语义审核保持独立。

仍保留 HTTP 字节/时间上限、8 MiB 检查点、工具和模型调用预算，防止恶意来源耗尽内存或无限扣费。这些是运行资源边界，不等于只让模型接收前几条发现。模型必须说明未完成的覆盖，不能声称已看完 hasMore=true 的资料。大规模候选按页筛选，不将全部全文一次塞入上下文。

## 验证、回滚与后续

覆盖超过 251 条候选的完整翻页、检索集合、去重、跨租户游标拒绝、上下文删除及到期清理。采集测试覆盖共享目录/私有关系、租约竞争、同站限流、日期顺序和重复采集。真实美联储 RSS 的两次采集用于验证更新幂等与原始日期，不把它当所有网站可用的证明。

升级前保留停止边界数据库和前版 binary/SDK。回滚 schema 时恢复对应数据库，不让旧 binary 打开新 schema。公共目录编辑不读取私人检索凭据。

追踪 SOURCE-01：公众号先用可用公开 RSS 或用户已有 WeRSS 的 RSS 地址；尚无 WeRSS 登录管理、B站/知乎/X 专用账号连接，不能声称已接入。引入时凭据按租户加密和独立授权。
追踪 SOURCE-02：候选/订阅全文检索当前用 SQLite 有界页读取与 SQL 过滤；达到大规模数据时测量扫描延迟后引入 FTS，不能预先添加第二套搜索存储。
追踪 SOURCE-03：付费搜索已提供服务端配置边界，前端自助密钥管理暂未开放。未来配置页面须保存后验证权限并支持撤销，平台不得借用某个用户的密钥编辑共享日报。
