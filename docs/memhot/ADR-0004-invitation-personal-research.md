# ADR 0004 — 从个人原话到次日多话题研究

日期：2026-10-12。状态：已实施，邀请测试。适用版本：0.2。

## 业务目标

用户白天留下对话、手记或导入文本；系统发现多个值得追问的方向，形成当日分话题总结，夜间查找证据，次日提供阅读和讨论。筛选是可选的：未操作的问题仍研究，明确删除、放下或解决的问题停止自动研究。不能把“全文被读取”当作“所有潜在议题均已找出”。覆盖率和模型推断分别表达。

## 领域与依赖

客户端捕获 → 本地语音门控与有界队列 → 本地转写或云端短暂转写 → 来源文本 → 分窗话题提取 → 每日总结 → 夜间研究 → 阅读、讨论与反馈。

账号和额度在调用外部模型前校验，独立于可删除的内容。个人认知由来源及明确用户反馈生成，不直接覆盖用户设置或凭据；研究只读有效认知。所有领域以服务端认证得到的 user ID 隔离，客户端不得指定租户。

- **捕获**：Android 前台麦克风服务，用户主动开启，持续可见通知和停止操作。真正的 VAD 优先滤除空闲片段；合法空转写是正常终态。离线模式不得悄悄向云端发送音频。
- **来源与话题**：全文按稳定窗口处理，逐字核对引用；来源与话题多对多。输出包含直接问题、潜在假设、证据缺口，未确认说话人不能被当作本人信念。人工编辑保留版本优先权，删除留下最小去重标记，晚到结果不能复活内容。
- **个人认知**：区分明确表达、AI 推断和手动填写；显示依据、可编辑/确认/删除。未知发言最多产生待确认候选，不能直接用于确定性画像；不推断敏感身份属性。
- **每日任务**：用户时区、夜间研究时间、晨间提醒时间独立。全部活跃方向进入可见队列；额度不足应显示等待，不静默截取前三个。SQLite 事务保证前序产物与下游入队原子提交。
- **账号与额度**：邀请测试使用邮箱作为登录标识、密码登录、一次性邀请；不伪称已验证邮箱或已发送邮件。测试套餐/充值明确没有真实付款。独立账本保留最小订单、余额和调用元数据；内容清理不能重新获得试用额度。旧用户通过绑定指定 ID 的邀请认领，历史数据不迁移到另一个同名账号。

## 信息架构与视觉

保留温暖中性色、阅读字体、细分隔线、适度留白。根代理亲自设计实现，不改为密集控制台。

- **录音（默认）**：独立主入口，大麦克风即开始/停止按钮。录音时显示从原生单调时钟取得的时长；导入对话和补充文字为下方折叠入口。转写选择、后台指南和同步恢复收在“录音设置”。
- **阅读**：日报与深度分析两个视图，按事件先总结再看原文，允许主动更新与不计费检查已完成内容；文章/事件可继续讨论。
- **思考**：按日期统一展示话题摘要，展开后展示后续问题与已有研究；不再拆成潜在问题/每日话题两个视图。支持日期筛选、分页、编辑、放下；未收起的新内容自动进入夜间研究。
- **对我的了解（个人偏好内）**：五维环形图连接真实兴趣订阅和认知记录。轮廓按各类已采用记录数量展开，仅反映记录数量；待确认条目独立标注，不计入形状。点击方向能查看依据、修改、删除或补充；复用同一编辑器和服务端版本校验，不建立第二套偏好数据。图形只在数据或选择变化时过渡，不做常驻动画。
- **个人偏好（第四个主入口）**：关注领域、对我的了解、推送与保存、账户与额度、数据与隐私统一收口；普通使用者不配置 API 密钥或私有服务器。
- **首次引导**：两个可跳过步骤，12个领域多选及自定义兴趣，再选择阅读和思考方式。目录由服务端校验；事务合并兴趣并生成有来源的人工认知，同一账户重复提交不覆盖人工编辑，两个设备并发只有一个提交生效。有有效兴趣/认知的旧账户直接进入应用。兴趣和认知仍为各自领域模型，不额外建立可失配的引导答案数据库。

## 数据驻留与保留

| 数据 | 本地 | 服务端 |
| --- | --- | --- |
| 原始录音 | 应用私有目录，仅待处理片段，有容量上限 | 转写期间临时处理，结束即清理，不纳入备份 |
| 离线模型 | 用户明确下载、校验后保留，可删除 | 仅公开模型下载元数据 |
| 来源文本 | 阅读期间的客户端状态 | 按用户期限保留，到期撤销依赖的派生内容 |
| 话题、认知、总结、讨论、研究 | 客户端必要缓存 | 以租户隔离，人工修改和来源撤销均需版本校验 |
| 抓取全文 | 无 | 短期保留后清理，仅报告保留必要引用 |
| 密码与会话 | OS 保护的会话令牌 | 密码哈希、令牌哈希、有期限会话 |
| 模型凭据 | 无 | 独立权限受限的运营配置，不发回客户端 |
| 测试额度账本 | 无 | 独立最小元数据，不随内容删除重置 |

处理模型供应商的音频留存受其政策约束，“服务端不保留”指 Memhot 自有服务器，不能代表第三方承诺。

## 并发与故障

有界后台并发、每租户后台串行、独立维护循环；模型调用不持有数据库锁。租约 attempt fencing 拒绝晚到完成/失败。调用预占与最终核销必须幂等；网络超时等未知付费结果保留状态而不自动重复调用。服务端重启不会丢失已提交文本和下游任务。

API 边界校验独立于模型输出校验；模型/抓取文本均是不可信数据。禁止日志打印原始对话、模型密钥、密码或令牌。测试充值不与任何真实支付网关连通。

## 取舍、验证与回滚

邀请期沿用 SQLite WAL 单服务与 Rust / React / Tauri，不引入 PostgreSQL、Redis、云端 shell agent。讨论使用有界搜索/引用工具；网页指令不能获取服务端执行权限。Android 优先交付，其他桌面端复用阅读与同步层；各平台常驻录音需要独立适配，不能因使用 Tauri 就宣称全部完成。

离线首选 SenseVoice int8：约 230 MB，成熟 Android 运行时；Qwen3-ASR 0.6B 现成 int8 包约 940 MiB，暂不默认下载。模型和运行时许可证分别保留。真机功耗和一加后台策略以实测为准。

验收包括长文本首中尾多议题、人工修改竞态、删除不复活、来源撤销、跨租户读取/扣款拒绝、重复充值和模型请求不重复计费、静音零外发、真实 ASR 和真实会议的多话题结果。上线前备份数据库并记录二进制 / APK 校验和；出现数据层回滚需求时同时恢复迁移前数据库和对应服务版本，不能仅换旧二进制。

## 公共编辑与个性化隔离

公共领域目录只能由运营方定义固定id、查询和来源。精确匹配这些目录的领域日报以领域、日期、语言和流水线版本为缓存键，同版正文仅存一份；每个用户保存授权范围内的投递引用。不得把私人问题、个人RSS、个人认知语句或私人搜索结果放入公共键或公共模型调用。自定义兴趣/RSS进入独立私有任务。多领域拆成多个有界子任务，不能在一个超时任务里悄悄省略后面的兴趣。

编辑流程借鉴AIHOT开源项目的两次独立筛选、同事件归并、结论优先和来源分层。初版仅使用自己的公开来源；0.3.3 在运营方确认适用书面授权后，增加默认关闭的 [AIHOT 官方 MCP 发现渠道](aihot-mcp.md)，保持 AIHOT 归属及原文链接。候选先固定快照，再评分、编写事件、独立事实审核；引文逐字核验、所有事实受源材料约束，编辑解读明确标注。未通过审核不发布。搜索与 AIHOT 聚合摘要只用于发现，不能冒充已读正文；编辑概览不能生成事实引文，官方RSS与文献摘要明确标注。

公共编辑使用平台独立每日调用预算，缓存命中不扣任意某位用户的额度。公共快照和抓取全文24小时清正文；日报保留30天，仍有用户引用的汇编保留至引用解除。未知付费结果不自动重放。旧版回退明确显示日期/陈旧状态，不冒充今日新进展。

免费检索采用本机隔离SearXNG（360 + DuckDuckGo实测可用，验证码/限流不绕过），补充官方RSS、arXiv、Crossref和Hacker News发现渠道。部署固定版本、内存与并发上限，不记录私人搜索词。私有研究按四个证据角度检索，先核对事实，再生成可推动思考的分析与具体验证步骤，并再次审核，不将市场热度当作付费证据。

自动深度研究按话题内容指纹去重：新话题和内容发生变化的话题在次夜全覆盖；未变的历史问题不会每晚重复付费研究。领域日报保持每日更新，用户可以主动发起新的研究。已排队/运行/等待额度的同类任务被手动更新复用，避免重复点击堆积任务。公共已删除投递保留最小墓碑，晚到结果不能复活卡片。后台任务840秒、租约960秒；公共汇编720秒、租约780秒，单模型调用自身限时不变。

云端是产品必备能力：账号、文字整理、认知和研究始终在云端，默认使用云端ASR。下载本机模型属于用户主动选装；下载不会自行切换转写位置，用户需明确开启本机转写。切换只影响语音转写，文字仍同步云端，不伪称整个产品离线。

## 真实模型引文容错（2026-10-12）

长会议首次验证暴露单个英文大小写变更导致整窗拒绝。现按条校验：正确条目先耐久保存；只允许空白和明确等价标点的唯一原文区间映射，并始终保存原始字节，禁止模糊语义、数字或大小写替换。无效引文最多一次独立、幂等的quote-only模型修复；仍失败保留可审计的退回条目和partial覆盖，继续其他窗口。重分析事务将旧覆盖归零，当前版本检查点分别记录扫描量、核验量及退回数。覆盖完成表示全文窗口已处理，不保证穷尽所有可能议题。

视觉采用用户给出的环形偏好示例，认知图只在「个人偏好」内展示，录音页不再承担偏好管理。直接克隆 shadcn/ui 官方仓库并适配 Select、Accordion、Dialog、Toggle Group，许可和固定版本见 THIRD_PARTY.md；Radix 管理键盘与焦点。沿用 CSS 变量与 SVG 图标，不另引入一套全局 utility 样式系统，也不复制 React Bits Pro 收费源码。原生后台录音不依赖界面动画。

## 移动端绘制约束

Android WebView 133上，独立模糊光晕层导致下方文字跨层残影；去掉filter、isolation或transform均未解决，隐藏整层可稳定消除且恢复可复现。0.2删除该装饰层，麦克风只保留静态阴影，避免以视觉效果牺牲录音反馈可读性。原生时长继续采用单调时钟，不受页面卸载与系统壁钟调整影响。
