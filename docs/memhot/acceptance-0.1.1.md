# Memhot 0.1.1 验收

日期：2026-10-12，Asia/Shanghai。设备目标为一加 Ace 3 / Android 16。0.1.0 的历史结果保留在 [原验收](acceptance.md)，本页记录后续改版与真实模型验证。

## 本次变化

主代理亲自设计和实现界面；协作代理统一使用用户指定的 GPT-6-Astra / xhigh，负责只读审核、真实服务验证与交付。未使用 Using Superpowers 或 Comet 工作流。

主导航收敛为今天、思考、记录，头像进入设置。今天分开问题研究与兴趣日报；思考按问题关联原话、缺口、材料和讨论；记录分文字输入与录音。阅读与讨论为专注页面。暖白、系统中文字体、柔和灰色、细分隔线和克制陶土强调替代原有混排界面。

保留阅读返回分类、问题上下文和内存草稿；录音状态入口直接进入录音控制。设置分组共享保存，隐藏字段校验失败时展示对应分组并聚焦。提交期间对应输入只读，避免旧请求清空新编辑。草稿不持久化到磁盘，账号切换、清理数据时清除。

真实调用修复了多条引文互相覆盖、范围限制误充反证、论文摘要误标全文、会议身份误归属和长文分析范围未明示的问题。报告采用简短标题，保留完整问题；讨论来源清单只显示实际引用的已授权 URL。见 [模型验证](model-validation.md)。

## 保留的限制

- 一加真机 8 小时耗电、通话中断和厂商后台策略仍未验收。模拟器锁屏通过不能证明最低功耗。
- 普通 Back 会将根 Activity 移到后台；划掉最近任务或系统强杀仍可能结束录音，未提交片段最多丢失 30 秒。应用引导说明保留最近任务。
- 公开搜索会出现同名词/宽泛词噪声；展示仅保留实际引用来源并不代表召回质量已解决。仅取得摘要时明确标记，不声称读完论文。
- 单来源最多分析 30000 字符，超出部分会显示范围提示；完整原文仍保存。长期个性化价值仍需多个真实问题持续验证。
- 当前交付 Android ARM64；Windows、macOS、iOS 安装包及真实 16KiB 页设备运行仍待分别构建验收。
