# ADR 0005：按事件编报与持续阅读

状态：2026-10-12 用户确认实施，替代0.2.0的临时摘录日报。

## 目标与边界

日报以概览、头条、分类、快讯、关联报道和往期组织；事件可追踪，资料可站内阅读，用户可收藏、搜索并按周/月回顾。继续使用现有Rust服务、SQLite隔离、React与Radix组件，不为新闻系统再引入一套账号或数据库。参考AIHOT的答案前置、事件概览与资料编排方式；提示词与领域实现由Memhot维护；不复制其品牌或运营数据。

公开领域：持续积累的候选与正文短期共享存一份；公共成刊由平台预算承担，用户仅保存授权引用。私人兴趣/问题：独立检索、收费、资料和报告，不进入共享候选池。公共报道不混入个人偏好，个人推荐与讨论在用户边界后执行。

## 数据流

### 统一的 SDK Agent 执行层

日报、个人研究、报告讨论都使用 Pi 官方 coding-agent SDK 的 AgentSession。三个工作流有不同的任务说明、工具范围和完成契约；模型根据已取得的材料决定继续搜索、读原文、调整方向或完成输出。工具结果由服务器提供，不以预先固定的搜索次数冒充自主研究。独立事实审核和引用校验仍是发布条件。

通过 Pi 的 createAgentSession 创建受控会话，使用其会话生命周期、工具循环、上下文管理与事件。SDK 运行在独立 Node 子进程，通过有界 JSONL 与 Rust 通信。Node 不持有供应商密钥；模型请求由 Rust 通过现有账本和网络边界代理。Rust 持有不可变的用户/公共领域身份、资料权限、总时限、调用次数、工具次数、任务取消和持久化检查点。子进程不暴露 shell、文件或任意网络工具。关闭隐式付费重试，任何实际模型调用都先经过 Rust 账本；未知扣费结果沿用账本的人工确认规则。

公共日报只有服务器目录资料和公共检索工具，费用进入平台预算。同一公共版面只存一份；用户偏好只决定订阅与私有推荐。私人研究与讨论只能读取当前用户授权的资料，不进入共享候选、公共提示词或公共调用缓存。检查点与工具结果和对应作用域一起保存，重试恢复相同输入，删除资料后不得继续提交旧上下文结果。

使用 Pi 的模型运行时和供应商适配处理 OpenAI-compatible、Anthropic、Google 协议；当前真实验收使用已配置的 DeepSeek。Node 版本与 SDK 版本随服务制品固定，部署与回滚同时切换 Rust 和 SDK 文件，不能只发布新二进制。

来源目录/搜索 → 去重候选与正文 → Agent 搜索、阅读、补证据、编排循环 → 独立审核与引用核验 → 最终事件集与概览 → 授权阅读/收藏/讨论。检索、引用验证和发布是确定性边界，研究过程由 Agent 决定。

模型未配置、编辑失败或没有合格材料必须返回可重试任务错误，不发布原始摘录冒充日报。旧摘录记录保留但标为未完成。证据有限的完成稿与执行失败分别表示。

## 对外数据契约

报告保持现有字段。editorial v3增加：

- `leadStoryId: string`；`highlights: string[]`（故事ID）；`sections: {id,title,storyIds:string[]}[]`。
- `stories`和`flashes`均为事件条目：`id,eventKey,title,summary,category,whyItMatters,readingGuide,evidenceIds,coverageCount,publishedAt?,tags?:string[]`。允许空快讯，禁止凑数。
- `overviewStatus: ready|unavailable`、`metrics:{storyCount,sourceCount,publisherCount,readingMinutes}`。
- 最终故事审核后再生成概览并独立审核，字数为指引，不能因181字丢弃事实。概览失败显式表达，不填固定套话。

新增阅读接口：

- `GET /api/v1/reading?period=all|week|month&q=&saved=false&category=`：授权的历史报告摘要、收藏状态，受限分页，全文搜索仅查本用户可读正文；周/月汇编源自已交付日报，不重新捏造事实。
- `PUT /api/v1/reports/{id}/saved {saved:boolean}`：幂等个人收藏。
- `GET /api/v1/reports/{id}/events/{storyId}`：当前事件与同主题已交付报告中的相关进展，返回已授权reportId；缺少已核实关系时仅称相关报道，不宣称同一事件。
- `GET /api/v1/reports/{id}/materials/{evidenceId}`：先校验报告与证据归属，再返回短期原文缓存或明确的摘要；缓存过期不伪称全文。
- `POST /api/v1/reports/{id}/materials/{evidenceId}/translation`：按需翻译，幂等排队、计入用户额度；读取材料接口返回翻译状态及内容，失败可见，内容过长截段必须明确标示。

## 故障、并发与保存

候选池抓取不消耗模型额度，限定批次、并发和总超时，来源失败后取下一候选；不得无限尝试凑数。模型结果沿用账本、预占和未知结果不重放规则。公共候选仅来自服务器固定目录。阅读与翻译按用户授权，不允许凭公共editionId或url越权。原始正文24小时清理，保留短引文与报告；收藏保留报告引用，不延长原始抓取正文。

## 验收

无模型不产日报；数学无关材料不进入AI产品日报；同事件多源聚合且引用有效；最终概览在故事淘汰后重新形成；空快讯诚实显示；历史/收藏/材料/翻译跨用户404；抓取失败补位且不越预算。真实模型产出一份包含概览和分类的新日报，浏览器412px与宽屏各检查一次，修复后复核；最后构建签名APK并核对公网下载。
