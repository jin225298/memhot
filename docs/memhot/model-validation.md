## 0.1.1 历史合成输入及首次发现

macOS `say` 生成 16.10 秒中文，转换为 16kHz、单声道 PCM16 WAV；没有采集麦克风。内容为研究语音识别非语音段幻觉、发生条件及不可外推的边界。

- 公网文本连接请求成功；ASR 任务完成，转写与合成稿逐字一致。
- 理解任务形成一个有逐字原话依据的问题，`origin=unverified_transcript`、`latestQuote.speaker=unknown`，未把录音说话人自动当作用户本人。
- 初次真实研究取得三项公开材料，并生成六条通过引文/相关性复核的结论。人工打开原站摘要核对，关键数字与限制存在于实际资料。
- 首次研究暴露三项缺陷：同一来源的后续结论覆盖先前引文与立场；“不能推广到所有模型”的推断被当作反证；获取 arXiv/ISCA 摘要 HTML 后错误标为正文。首次报告不是最终质量验收结果。

合成场景的两项被引用资料：[Calm-Whisper 原站摘要](https://www.isca-archive.org/interspeech_2025/wang25b_interspeech.html)、[Whisper 非语音幻觉研究摘要](https://arxiv.org/abs/2501.11378v1)。正式会议主题和其派生正文不在本记录披露。

修复后每条 citation 独立保留 claim、quote、type、stance；来源摘录组合所有已接受引文。范围限制和推断降为 context，实证反证还需在复核中明确认可，来源不足继续 partial。已知论文摘要页仍标 `metadata_or_abstract`。

## 实际边界

此次单段合成语音一致不能证明嘈杂环境、方言、多人交叠或目标手机采集准确率。模型复核使用同一供应商的独立请求，并非外部独立事实核查。公开搜索覆盖和网站可读性仍有限；摘要证据不代表已阅读全文。研究是否 ready 取决于材料质量，不能以 HTTP 200 或任务 completed 代替判断。
