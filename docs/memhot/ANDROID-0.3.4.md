# Android 0.3.4 / 1007：阅读排版与思考整理

## 变更

日报与调研报告统一为阅读页面：清晰标题、导语、正文、阅读目录、按需展开的资料区和可横向滚动表格。AIHOT 日报注明来源，保留其栏目与快讯。

思考按日期或分类分组，历史默认收起，支持搜索全部历史、时间/分类筛选和已归档切换。删除入口与打开、编辑分开；确认中可选择减少类似推荐。新增和修改问题的关注项可在个人偏好中编辑。归档保留内容并暂停对应研究，删除会清理关联材料和讨论。
