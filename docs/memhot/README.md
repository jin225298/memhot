# Memhot — 录下日常，接着思考

Android 优先的邀请测试应用，React / Tauri 阅读界面、Android 原生持续录音、Rust 服务端。软件内使用邮箱、密码与一次性邀请码登录；普通用户无需设置服务器或模型密钥。测试充值不会产生真实付款。

## 使用顺序

1. **录音**是默认主入口。点击大麦克风开始/停止，录音时显示持续通知与时长；导入对话和补充文字在下方折叠入口。
2. **思考**按日期展示话题摘要，展开后查看后续问题和已有研究。可补充、修改、删除或放下；不必逐条确认，新的、或内容改变的未放下方向会进入夜间研究；未变旧问题不会每晚重复付费研究，可主动更新。
3. **阅读**区分围绕个人问题的深度分析与兴趣日报。日报先概览，再分事件说明变化、阅读理由、原文与扩展材料；可从任意事件继续讨论。推送未到时可主动更新，或只检查已经完成的内容。
4. **个人偏好**是第四个主入口，集中管理关注领域、我的订阅、对我的了解、推送与保存、账户与额度、数据与隐私。个人偏好内的环形图连接同一套认知，可查看依据和编辑；未知说话人的发言不会自动变成用户的信念。

首次登录分两步选择：12类兴趣及自定义方向，再选择阅读方式与思考偏好。可以跳过；保存是单次事务，重复提交不覆盖后来的编辑。选择形成明确的人工偏好，后续在「个人偏好」调整；已有兴趣或认知的账户不强制重做引导。

界面组件从 shadcn/ui 官方源码适配，使用 Radix 的 Select、Accordion、Dialog 和 Toggle Group；日期选择、话题展开、多选引导与偏好编辑由统一组件承担，录音页不再显示认知图。

## 录音与转写

Android麦克风前台服务使用16kHz单声道采集，Silero VAD过滤无声片段、30秒上限分段、耐久有界队列；连续有效空结果暂缓外发。录音中没有持续WebView波形。锁屏录音需要partial wakelock，不能据此宣称零耗电。

- 云端模式：音频在Memhot服务器内存中完成转写，文字耐久提交后确认，音频不写入服务器持久目录；失败不保留新音频。第三方ASR供应商的留存由其政策决定。
- 本地模式：明确下载SenseVoice Small int8（下载约156MB，模型约230MB），SHA256校验、受控解包，使用Android运行时转写。失败不会静默改用云端；转写文字仍会同步用于整理和研究。
- 待处理片段只在手机应用私有目录保存，最多512片段/256MiB；满载暂停。确定提交文字或空结果后清理片段。未知云端付费结果不会自动重复；用户可明确确认重试。

一加Ace3 / Android16需允许麦克风、通知及后台活动；重启、强行停止或厂商回收后应重新打开检查。已完成模拟器验证不代替真机8小时续航测试。

## 日报、研究与存储

公共固定领域按“目录主题＋日期＋语言＋版本”统一编辑、正文只存一份，用户各自保存投递引用。私人问题、定制兴趣、私人RSS、认知和讨论不进入公共缓存；共享日报使用平台预算，不扣首个读者的模型额度。编辑流程参考AIHOT的开源设计，并可在适用书面授权和运营开关下使用其官方 MCP 发现渠道，见[归属说明](THIRD_PARTY.md)。

免费搜索经隔离SearXNG，配合官方RSS、arXiv、Crossref和Hacker News发现入口。两轮独立评分、同事件归并、逐字引文与独立事实审核后发布；搜索片段不能冒充已读原文。私人研究包含不同证据角度、来源核验、推演和下一步验证。没有足够证据时明确保留缺口。

“我的订阅”支持添加网站或 RSS、导入 OPML、查看文章和更新状态，以及主动更新、暂停和取消订阅。来源内容收录 30 天，进入日报/研究时按兴趣与个人偏好选取。检索候选分页保存，不再只让模型收到最前面的几条；未读线索必须核对原文后才能引用。公众号、B站和知乎的专用账户接入尚未交付。

原始文字按7/30/90/365天保留。来源撤销会同步撤销依赖内容；人工独立认知单独管理。抓取全文和公共编辑输入24小时后清正文；公共版通常30天，仍被用户引用的版本延长至引用解除。账户与测试账本独立，删除内容不会再次获得试用额度。

服务端为聊天、翻译、日报、研究分别预留容量；同类后台任务按用户轮转，关联的整理与研究仍按顺序执行。保留调用幂等与额度预占，详见 [并发设计](ADR-0012-workload-concurrency.md)。未知付费结果保留最小回执，不自动重发。备份保存最近七次成功副本，因此主库删除不代表备份即时删除；即时清除需同时处理相关备份。

## 交付边界

当前交付Android ARM64安装包。Windows/macOS/iOS可复用界面与同步层，但尚未交付安装包，各平台持续录音需要独立适配。日报通知使用WorkManager，可能受Doze/厂商策略延迟；主动更新是明确入口。未绕过登录、付费墙、验证码或平台反爬；搜索覆盖和来源稳定性均有限，不能声称遍历全网。

邀请期邮件仅作为登录标识，未接SMTP邮箱验证；邀请码与密码重置码由管理员安全提供，不会假称邮件已发送。没有真实支付、自动续费或云端shell agent。讨论使用有界检索和资料读取工具。
