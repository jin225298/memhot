# ADR-0009：日报先形成条目，再编排成刊

日期：2026-10-13。状态：已实现；真实 MCP 及领域成刊验证通过，领域素材覆盖仍有限。

## 依据与范围

用户要求 AI 领域可直接阅读 AIHOT 日报；其他领域参考其开源生成过程，不复制 AI 新闻充当其他领域的日报。已确认的在线内容授权继续适用。

核对上游 `KKKKhazix/AIHOT` 提交 `652bd6bf4190df0030824dd86a982ea96f5623d5`：

- `packages/backend/src/reports/compose.ts::composeDaily`：日报由规则成刊，导语来自头条已有摘要，不调用模型。
- `packages/backend/src/reports/edition.ts`：一个事件一条，记忆过去七期，主报道优先权威来源，同一来源最多两条正文，其他内容进入快讯。
- `industry/selection.ts`、`industry/prompts/selection-score.md`：资料先独立评分两次，再按来源分级门槛选入。评分关注实质变化、信息增量、证据和对读者的价值。
- `packages/backend/src/publication/reports.ts::dailyWithNotes`：MCP 日报包含原始日期、窗口、完整分栏条目及快讯。MCP 当前的结构化日报不提供站点的全部 related/highlights 字段；不凭空补出这些数据。

## 决策

1. AI 日报走匿名只读 MCP 的成品内容路径，完整保留接口提供的导语、栏目、摘要和原文链接。跨用户只存一份刊物，账号只存阅读引用。此路径不调用文字模型，也不改变过去失败模型调用的账本。
2. 外部成品标记为 AIHOT 编辑内容。它可以被阅读，不等于 Memhot 已核对原文；讨论仍须读取原文才能把原始链接作为事实依据。来源日期与抓取日期分开保存，不用同步时间伪造新闻新鲜度。
3. 其他领域继续使用 Pi harness 搜索、阅读、提取及事实审核。成刊改为对审核后的条目进行确定性排序、来源均衡、去重、分栏及头条摘要复用；取消整期必须额外润色、重新生成总览才能出版的依赖。评分标准、范围与输入版本保留审计。
4. AIHOT 在北京时间 08:00 成刊；夜间研究不提前获取昨日刊物。独立同步在 08:05、08:20、09:00 设置最多三次机会，已有当期个人引用或待处理任务时不重复排队。展示时间保留用户设置；当期内容尚未发布时保留原刊期，不冒充当日。
5. 事实审核不通过时，最多一次受限修订，再交给独立事实审核：仅可修改标题、摘要、解读、阅读角度和局限，或删除不支持的条目。已通过条目、事实引文、证据、日期和 ID 不可更改；修订/复核都有稳定收据，不重放未知或已完成付费调用。
6. 逐条、长期摄取与完整事件关系库是下一阶段工作，不能把当前批次处理描述成已复制 AIHOT 全套采集引擎。每项增量须有测试与真实日报验收。

## 故障与回滚

外部日报缺字段、来源不合法、未来日期或时间窗口错误时拒绝导入；临时不可用时仅返回标明原日期的已有刊物。租约限制并发获取，数据库唯一键防止重复保存。正文通过现有纯文本/Markdown 渲染，不执行外部指令。

切换 DeepSeek 官方配置已单独完成，备份在服务器私有部署目录；ASR 配置保持原值。日报变更保留旧刊物和旧模型收据，回滚二进制与 agent bundle 即可，不重置账本。
