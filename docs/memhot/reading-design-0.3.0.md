# 阅读界面 0.3.0

延续已确定的四栏：录音、思考、阅读、个人偏好。此轮只扩展阅读，不把账户、录音或偏好重新塞进阅读流程。

阅读列表先按深度研究/兴趣日报分组。搜索、近一周/近一月、收藏在同一过滤区；更新/同步仍在内容上方。周/月是已收到内容的回顾，文案明确说明，并不冒充另一次深度分析。没有结果时可以清除筛选；新用户回到录音或关注领域。旧版只有摘录的日报折叠放入未完成记录。

报告按概览、重点目录、头条、分类报道、快讯、出处逐层展开。资料在独立阅读页呈现，可回到报告、打开原文和按需翻译；正文过期时明确显示摘录。事件进展仅串联当前用户已收到的报告；同一事件和相关报道使用不同标签。收藏是个人状态。

复用现有 shadcn/Radix Select 与按钮设计，继续使用暖白纸色、石色文字、陶土色重点和正文衬线标题。不增加泛用仪表盘卡片。窄屏筛选分两行，资料按钮和阅读操作保留触控面积。加载、失败、重试与异步取消各自可见；工具操作轨迹不展示模型隐藏思考内容。

验收：真实生成内容与模拟边界内容分别标识；412px和桌面检查筛选、收藏、原文/译文、返回、相关进展；完成一次批量修复再复核。不把构建通过当作视觉验收。
