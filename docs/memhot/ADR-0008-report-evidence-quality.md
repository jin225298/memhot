# ADR 0008：报告质量由问题覆盖和原文证据决定

日期：2026-10-13。状态：已部署 0.3.7；验收分别见 acceptance-0.3.5.md、acceptance-0.3.6.md 与 acceptance-0.3.7.md。

## 问题

实际报告存在四类错误：单篇泛化文章支撑长篇建议；同一来源的多个有效引文被按网址去重丢弃；会议中未确认身份的发言被写成用户当前经历；新闻页的动态日期让旧报道进入日报。部分模型响应已完整结束但未遵守 JSON 格式，导致有用正文丢失。阅读质量不能用报告长度、来源数量或任务 completed 单独衡量。

## 决策和边界

- Pi 仍负责有界检索和阅读。先收集证据，再独立审核其相关性、适用范围、发言归属及问题覆盖；不足时最多补检一次。原始研究、当事方声明、独立报道与意见分开判断，厂商发布不能证明独立效果。独立证据按原始研究或观察主体计算，不能把同一研究的转载算作多份验证，也不能把同一论文平台上的不同研究视为一个来源。
- 研究正文基于审核通过的 claims 写作，增加一次无工具、仅改文字的语义修订，再独立审核是否回答问题及是否给出具体动作、观察信号和改变判断的条件。修订不能变更引文、来源 ID、日期、章节对应关系或事实类型；重点删除未经比较的首个/唯一/首要判断、单一案例的全局外推，以及将探索观察期误作需求成立阈值的说法。证据不足允许诚实的部分结果；不得用篇幅或虚构反例补齐。未来验证方案不要求其结果已经发生。
- 章节审核使用独立 `sectionId`，证据命题仅放在 `evidenceForReference`。返回项必须恰好覆盖全部章节、无重复及越界；错误地审核命题编号不能被当成章节通过。此问题已在真实模型中复现，不能依赖提示词保证对象绑定。
- 补检与写作分别受总预算约束：证据工作合计 600 秒，写作 210 秒，给 840 秒任务期限保留提交余量。可选补检失败回退整套已审核原文和证据。权限、数据删除、存储、计费冲突不能被降级吞掉。未知付费响应继续保留原回执，不自动重放。
- 完整响应的格式错误允许一次独立、计费、无工具的格式转换；不能补事实、来源、日期或审核结论。截断和未知结果不进入格式转换。每个转换阶段沿用稳定任务身份，避免重复扣费。
- 研究命题按来源和引文去重，不按改写后的命题文字计数；重复项优先保留原有更保守的 inference/context 表述，不自行改写证据。审核规则进入阶段指纹，避免沿用旧规则结果。
- 日报同样先修订分析文字再审核；综述和审核阶段绑定最终接受内容，抓取时钟不影响修订身份，发布日期及内容变化会改变身份。
- 日报引文只去除完全相同的重复项；审核能看到每个引用附近的原文与截断信息。总览失败时抽取已审核摘要，不能把标题串联伪装成总览。只有历史回顾或一条新资料时标为阅读摘选/部分结果。事件发生时间与文章发表时间分别判断。
- 网页发布时间在 Rust 读取原始 HTML 时获取，不能依赖插件输出或抓取时间。36 氪只接受 URL 对应文章状态中的 publishTime；不能借用同页推荐文章或动态 meta 日期。无法核实则保留未知。
- 达到发现容量不能把实际检索命中伪装为空结果。私人网页、AIHOT 与论文发现返回最多 8 条未入库 leads（无 sourceId、不可引用）；只能经 open_page/papers read 取得原文后进入证据池，保留已有来源与 ID。公共检索不扩展任意 URL 读取权限。此设计修复真实补检的空结果退化，不能以放宽 ready 或编写更多无依据分析代替。
- 公开 PDF 通过同一 Rust DNS 固定与重定向校验路径取得，在隔离的 unpdf Worker 中提取，沿用锁定依赖中的 unpdf 1.8.1。8 MiB、40 页、17,500 字、15 秒限制及取消释放防止共享服务被大文档拖住；只提取可得文本，不做 OCR 或权限绕过。PDF 创建/修改时间不能作为发表时间。extraction 元数据与引文正文分离，经过工具、检查点、公共输入和讨论恢复仍保留；摘要回退、正文裁剪另行标记，不能冒充整份报告已读。来源下载超限可让 agent 换资料，通信或协议超限仍中止。
- 模型响应以 SSE 事件而非单行 JSON 校验，匹配当前 SDK 的 BOM、换行、多行 data 及结束边界。OpenAI DONE 后不再寻找结束原因，Anthropic 必须是有事件空行的命名 message_delta。坏 JSON、截断或未取得有效结束原因不会成为成功回执；诊断只保留固定形状与计数，不记录模型正文或网关错误消息。
- 每轮最多 40 份资料，其中发现阶段上限 32，剩余容量用于打开原始来源。达到上限仍能读取已发现资料；不驱逐已引用原文。
- 私人兴趣分别查询，沿用现有两条预检预算按日轮换，其余主题明确交给 agent 补检。个人编辑只接收筛选后的私人兴趣和订阅来源；公共版本仍限定目录主题，不使用私人文献库、偏好或对话。

## 演进与回滚

研究、日报和公共缓存流水线分别版本化。旧公共候选网址可在新流水线下重新编辑一次，同版本重复输入仍受无新来源保护。旧报告保留历史；更正必须有记录和备份，不能悄悄改写原始对话。

本次不增加 API 或数据库契约，客户端 0.3.3 可继续读取。新增 editorial limitations/reportingKind 属可选字段；旧客户端的专用日报视图未独立显示 limitations，正文中仍保留，不能宣称已完成新客户端展示。部署保留上一服务版本、配置和停止边界数据库，可按既有发布流程回滚。

## 已知限制

审核先指出最可能越界的原句、原文实际范围和字段间矛盾，再给判定；示例不能默认全部通过。正常有条件的推演与探索建议不等于新增外部事实。最初思路中的 gaps 不再无条件追加到研究结果。

模型审核仍可能遗漏语义错误，不能称为事实保证。网页和论文原文有长度、访问权限与检索预算限制；未取得的全文不能冒充已读。代理不能通过多次自动付费重试掩盖提供商的不完整响应。验收必须同时检查实际报告内容、来源及诚实的未完成标记，而不仅是 HTTP 成功。

## 0.3.8：外部来源与本地推演的边界

正式生成实例显示，连续引文匹配、scope/attribution 通过仍可能接纳会议规则或本报告拟定的实验。新增 `sourceBound` 必填审核，发布与覆盖共用门禁；同引文候选先审后去重，避免污染推断挤掉真事实。编辑输入保留原始引文。分析建议允许合理推演，但不得借来源标签伪装为已实施实验；需求、模态增量与方案采用分别判断。

该门禁仍依赖模型语义判断，不是事实保证。0.3.8 的隔离模型回测被网关不完整响应中断，没有语义验收结果；专项修订的用户报告明确保留编辑说明，不冒充全自动成功。纯方案问题的写作准入限制跟踪为验收文档中的 MQ-008。
