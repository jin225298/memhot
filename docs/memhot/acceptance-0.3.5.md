## 真实输出暴露的问题

审核曾返回 20 个命题的判定，而输入需要审核 5 节正文。旧代码用数字索引匹配，可能错误接受不对应的审核；现在使用独立 sectionId，必须恰好覆盖全部章节且无重复、多余或遗漏。最终回归返回正确的 5 个章节判定，2 节被拒绝。先前未正确绑定对象的通过记录无效，不能作为发布依据。

模型也曾只修正文，留下标题或验证条件中的原判断。私人修订现在要求完整返回摘要、章节标题与正文、动作、信号和改变判断条件；日报修订只允许更改分析字段，事实、摘要、日期与来源不能借修订阶段改变。最终审核同时检查各字段矛盾。综述身份绑定最终接受的条目，避免过滤后沿用旧总览。

最初思路的 gaps 不再无条件拼回已研究报告，避免找到有限使用证据后仍声称“没有任何使用证据”。未知发言人不当作用户经历；不同研究的证据独立性按研究主体而非同一论文平台计算。

## 上游故障与预算

实网运行遇到过不完整模型响应、90 秒超时及完整正文格式不合约。未知响应保留付费围栏，没有清空失败记录或自动重放。已完整结束的回答只允许一次独立、计费、无工具的格式转换；不得补事实与判定。最后一次全新私人检索因提供商不完整响应未完成，后续只复用已完成检索稿开展明确授权的新版验收，不将故障掩盖成成功。

语义修订使用精简输入与有限输出；完整原文仍进入最终证据审核，不能用精简的修订上下文替代事实检查。模型 HTTP 客户端不再继承网页的 60 秒限制，采用文本阶段的 90 秒预算；仍受阶段与任务总期限约束。日志仅保留协议形状和错误码，不记录原始响应、凭据或个人提示词。
