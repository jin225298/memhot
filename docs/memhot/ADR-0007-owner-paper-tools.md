# ADR 0007：个人论文连接与公共资讯分离

日期：2026-10-13。状态：实施。

## 业务边界

用户授权 alphaXiv 用于论文检索、原文阅读和个人文献库。它带有个人身份与独立供应商额度，不能与匿名 AIHOT 公共发现采用相同的跨用户缓存策略。用户同时要求切换托管文本接口的 DeepSeek v4.1 模型，ASR 与文本模型保持独立。

## 决策

1. Pi agent 继续负责有界的研究/编辑/讨论工具循环；Rust 负责用户权限、调用回执、网络和敏感凭据。只向匹配配置 tenant 的私人 Scope 提供论文工具。公开共享版没有论文凭据权限。
2. 第二个真实 MCP 用例才提取通用只读传输。服务地址、身份、工具参数、原文判定及缓存仍由具体业务模块控制。Pi 子进程不能指定服务器、携带 Authorization 或启用任意工具。
3. 公开论文原文经过现有证据审核；alphaXiv 默认 AI 报告与检索片段不等于原文，必须请求 `fullText: true`。原始发表日期未知就保持未知。
4. 请求在外发前事务性记录不可重放的内容无关回执；同时保留 24 小时的私有原文/文献库结果。临时内容删除不能重新授权同一研究的供应商调用。用户清空所有数据时删除这类无内容回执。
5. 当前邀请期绑定一个明确的现有用户；有效邀请可指定尚未认领邮箱的原用户身份。不能因邮箱尚未注册而创建替代用户或默认给所有人使用。禁用账号不能依靠旧邀请再次获取权限。
6. 托管文本模型按供应商实际 `/v1/models` 清单选择 `deepseek-v4.1-flash`。模型、端点和密钥作为一个经过真实 SDK 调用验证的配置切换。旧冻结请求不暗中替换模型或重复未知扣费。

## 取舍与后续条件

此轮以公开 arXiv 文献为范围，私人上传 PDF 不提供原文读取。文献库只读，不自动修改、移动或删除收藏。单账号服务端配置便于邀请测试；第二个用户需要独立连接时，应改为每租户凭据存储/撤销/限流，不得扩展成共享个人密钥。接口工具名或响应格式变化时必须更新相应夹具并经过真实读取验收，未知格式失败并允许研究使用其他来源。

回滚时还原已验证的模型配置、论文配置和旧发布链接；保持既有资料与用户余额。Android 0.3.3 使用稳定 API 接口获取这些新能力，不需要为一次模型切换重新安装。
