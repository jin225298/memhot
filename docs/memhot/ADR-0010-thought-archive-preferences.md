# ADR-0010：思考归档与用户主动偏好

日期：2026-10-13。状态：已实现。

## 边界

思考记录用于问题管理；用户偏好用于之后的整理、检索和研究，两者独立存储。归档不是“不感兴趣”，删除也不自动代表整个领域不感兴趣。

## 决策

- 思考默认显示正在关注的问题，按个人时区日期收起历史；可按分类浏览、筛选日期、全文搜索，另有“已归档”。服务端先按账号与完整筛选条件查询，再做游标分页；搜索不局限于当前已加载页面。
- 删除与打开、保存分开。列表及详情给出明确删除入口；弹窗说明影响，取消优先获得焦点。“以后少推荐类似问题”默认不选，选中才产生针对该问题的显式偏好。归档保留正文与已有材料，不产生负面偏好。
- 用户主动新增或实质修改问题，形成“希望了解这个问题”的可编辑关注项，不推断用户已经赞同某观点。修改分类、归档或重复保存不重复创造兴趣。
- 负面偏好保存用户限定的相似问题范围，不能扩大为排斥整个领域。新增和减少推荐使用稳定的记录 ID 幂等保存；已经手动修改、停用、删除的偏好不被自动覆盖。
- 后续整理与个人研究读取当前启用的偏好，限制数量及总字符数；这些内容作为资料，不能变成工具指令或覆盖安全边界。用户可在个人偏好中随时修改或删除。
- 归档在同一事务取消当前思考的未完成研究；开始、付费预占、检查点与发布均重查状态。已经发出的外部请求不可追回，晚到结果拒绝发布，收费收据保留。恢复只允许用户明确发起新任务，旧任务不重放。
- 删除与反馈使用 revision 校验，事务中处理相关记录；请求只作用于当前账号。重复删除是幂等结果，其他账号或不存在的记录不暴露状态。
- 日报和深度研究共用阅读纸面、目录、段落节奏、资料折叠和表格横向滚动。阅读库按日期收纳，保留搜索、内容分类、时间范围与收藏筛选。

## 兼容与验证

既有无分类思考显示“未分类”；旧接口默认状态筛选仍为 all，旧无筛选游标继续按对外契约支持，新增游标绑定筛选条件。现有正文、刊物及付费收据不清空。覆盖多租户、时区边界、游标、乐观并发、手动偏好优先和取消研究的数据库回归。前端使用合成内容验证移动/桌面布局与交互，正式 APK 单独验证签名与原地升级。
